# Task 1.2 — Off-token value audit (`theme/` + `components/`)

Date: 2026-09-02
Scope: `theme/` (tokens, palette, typography, shape, spacing, shadows, index, augmentation, theme/components/*) and `components/` (React library). `node_modules` / `dist` excluded.

## Method

Greps run over `--include='*.ts' --include='*.tsx'` in both trees:

| # | Pattern | Purpose |
|---|---------|---------|
| 1 | `#[0-9a-fA-F]{3,8}\b` | hex colors |
| 2 | `\b(rgba?|hsla?)\(` | functional colors |
| 3 | `[0-9.]+(px|rem)\b` | sizes (also per-file counts) |
| 4 | `[0-9.]+m?s\b`, `cubic-bezier`, `steps(`, `@keyframes`, `animation`, `transition` | timing / easing |

Then each hit was read in context and classified:

- **token-traceable** — the literal equals a value in `theme/tokens.ts` (or is derived from it); swapped for the token reference where it was a literal in code.
- **legit-exception** — per the task's exception list: values inside `tokens.ts` itself, comments, `transparent`/`currentColor`, `1px` hairline rules (plus the system's consistent 2px/3px chrome rule weights, which are DESIGN.md's border weights, not color/rhythm decisions), the reduced-motion accessibility floor (`0.001ms`), MUI structural values, and canvas/boxShadow/textShadow **alpha variants of token hues** (base hue is a token; alpha used for borders/glow/overlays).
- **VIOLATION** — no token carries the value; fixed by tokenizing (existing token, or a new named token added to `theme/tokens.ts` carrying the exact same value).

### components/ — sizes

Sizes are dominated by component-internal numbers (grid columns, canvas dims, icon boxes, dense-console paddings). Classification: `1px` hairlines are the sanctioned exception; `2px`/`3px` are the system's chrome rule weights (DESIGN.md); the rest are component-internal geometry that does not claim to be a token. **No size was rewritten** — a full spacing/type-scale token group is a design decision, not a stray-value fix. Flagged as a possible follow-up: add a `typeScale`/`size` token group to `tokens.ts` and migrate component font sizes (10/11/12/13/26 px and the `0.625–0.875rem` cluster already mirrored in `theme/typography.ts`) onto it.

## Tokens added (`theme/tokens.ts` — values identical to the literals they replace)

```ts
// hue (augment / hazard accents)
orangeHi:  '#FF8A3C'              // palette secondary.light
orangeDeep:'#C25400'              // palette secondary.dark
hazardBg:  '#170303'              // status-marquee ticker field
black:     '#000'                 // hazard stripes & hazard fields only
white:     '#fff'                 // hazard-field content (corner chips)

// surfaces (emitted as palette.nerv CSS vars)
overlay:      'rgba(255,255,255,.06)'
overlayFaint: 'rgba(255,255,255,.04)'
backdrop:     'rgba(0,0,0,0.82)'

// motion.durations
complex: 160   // MUI "complex" structural transition
slide:   300   // continuous meter fill
```

`theme/augmentation.ts` was extended with the matching keys (`NervTokens.hue.*`, `NervPaletteTokens.overlay|overlayFaint|backdrop`, `NervTokens.motion.durations.{complex,slide}`) so the new tokens are typed on the theme. No existing token value changed.
