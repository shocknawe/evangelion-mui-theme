### Exception 3 — Brand / SiteHeader layout hardening (commit `3b1a844`)

Attribution: `3b1a844c7a862a09b7944958778605b0dad0d020` — "fix: possible
issue fix", 2026-08-30, **an early pre-task commit on the branch (9th after
the merge-base, before the openspec scaffolding)**, predating every numbered
task commit. It carries **no task
number** in its message and is not claimed by any `tasks.md` row; it also
shipped the `ZoneTitle` `component` prop + `mt: 0` in `components/layout.tsx`
(opt-in heading element; default `div` render unchanged, already covered
under (b) above) and doc-site scaffolding.

What changed visually:

- **No** color, typography, glow, shadow, border, radius, or token value
  changed anywhere in these hunks — every pre-existing declaration
  (`fontSize: word`, `color: hue.mintHi`, `textShadow: 0 0 6px rgba(82,242,154,.6)`,
  `letterSpacing: '0.04em'`, mark size, version-chip styling) is identical.
- **Rendering-behavior changes that are real:** (1) the wordmark is now the
  elastic part of the lockup — in a container narrower than the lockup it
  truncates with an ellipsis instead of forcing the bar wider (the `py`/`my`
  pair only widens the clip box so the phosphor glow is not shaved off the
  caps); (2) the header bar clips overflow instead of growing; (3) below
  `md`, where the nav is hidden, actions now take `ml: 'auto'` and push to
  the right edge — previously they sat flush after the brand when links
  existed. At desktop widths with a comfortable container the default
  render is unchanged.

Adjudication: under the constraint as written (no visual **identity**, no
**token value**, no **variant behavior** change) this is not drift — the
identity values are untouched, nothing is a variant, and the deltas only
manifest at constrained widths / below `md`. It is, however, a genuine
default-render change with no task attribution, so it cannot be counted
under category (b) and is recorded here as an exception needing explicit
coordinator sign-off rather than silently absorbed. Not raised as a blocker:
the commit message and its diff are consistent with a deliberate
container-robustness fix (the in-code comments state the intent), it
protects the "everything important is boxed" grammar from overflow rather
than restyling it, and the only user-visible delta (small-screen actions
alignment) corrects a layout defect (actions orphaned next to the brand once
the nav hides at `xs`).
